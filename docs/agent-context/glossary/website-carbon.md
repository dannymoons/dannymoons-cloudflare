Every website uses energy. Every page load requires a server to process the request and send data over the internet. That energy has a carbon footprint, depending on where the electricity comes from.

Website carbon is measured in grams of CO₂ per visit. A lightweight, well-optimized site on green hosting can be under 0.05 grams per visit. A heavy, poorly optimized site on fossil-fuel-powered servers can be several grams — 50 to 100 times more.

I set a target for myself: every site I build should emit less than 0.05 grams of CO₂ per visit. That means choosing green hosting, optimizing images, writing clean code, and removing unnecessary scripts.

It is not just about being green. Lightweight sites are also faster, cheaper to run, and better for users on slow connections.
