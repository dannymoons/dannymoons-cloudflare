The Green Web Foundation is an independent organisation that keeps track of which web hosting providers use green energy. Think of it as a green energy certificate for the internet. But that's only one piece of their puzzle. They also provide datasets, [CO2.js](https://www.thegreenwebfoundation.org/tools/c/) and training of sustainable software.

## Greenhost check
When a hosting provider is listed in their database, it means the provider has proven that their servers run on renewable energy. Tools like [Carbonfooter](/what-is/carbonfooter) use this database to check if a website is truly green.

For me, this is important because it turns "we care about the environment" from a marketing claim into something that can be verified. It is the difference between saying something and proving it.
