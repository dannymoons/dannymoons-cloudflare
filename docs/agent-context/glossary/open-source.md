Open source means that the code behind a piece of software is publicly available for anyone to see, use, and improve.

Think of it like a recipe book. With closed software (like Microsoft Word), you get the finished dish but you cannot see how it was made, and you cannot change the recipe. With open source software (like Penpot, Payload CMS, or Linux), the recipe is published for everyone. You can see exactly how it works, modify it for your own needs, and even share your improvements.

For Danny, open source is important because it gives freedom. No subscription fees, no lock-in to a single company, and the ability to customize the software to fit exactly what a project needs. It is also more sustainable, because the software can live on even if the original creator stops maintaining it.
